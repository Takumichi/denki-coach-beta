# 現場でんき探偵 Pro 🕵️‍♀️⚡



新人電気工事士向けの、現場準備・工程確認・記録を支援するWebアプリです。



現在はβ確認版として、画面表示や操作性、現場での使いやすさを検証しています。



## 開発メンバー



- **ひろみん❣️** — プロジェクトオーナー・企画・最終承認

- **ラン⭐️（Claude Code）** — コード実装・修正・技術確認

- **ひな🎀（ChatGPT Codex）** — 設計支援・実装・QA・GitHub運用支援



## 開発履歴の管理方法



担当者が分かるように、commit・PRタイトルの先頭へ担当者名を記載します。



例：



- `ラン⭐️: 表示不具合を修正`

- `ひな🎀: ナビゲーションを改善`

- `ひろみん❣️: 仕様と開発方針を更新`



すべての変更は作業ブランチで行い、PRで内容を確認してからmainへ統合します。

## 注意事項



本アプリは、第二種電気工事士の新人社員向けの予習・記録・確認支援ツールです。



実際の施工判断は、所属会社のルール、現場責任者、上司、有資格者の指示に従ってください。
